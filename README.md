# TP7_barBariles
Mi base de datos :).
Lista de tablas: 
1. Turno
2. Barbero
3. Cliente
4. Servicio
5. Pago
6. Método de pago
7. Horario
8. Sucursal

---
La tabla turno presenta, analógicamente, los datos de una persona que necesita un corte de pelo, que serian el horario y la fecha.

 La tabla barbero registra los datos de uno de los empleados del local, tales como su nombre y apellido, su numero de teléfono y gmail.

 Luego hice la tabla Cliente, que se encarga de poseer todos los datos del cliente en cuestión, como pueden ser su nombre y apellido, su DNI que se registra en forma de id, su numero y gmail.

 Para los diferentes servicios que ofrecen los locales diseñe una tabla llamada servicio donde se computa su nombre del servicio en cuestión, su valor y la duración estimada del procedimiento de este servicio.

 Para abonar cada servicio cree la tabla pago y Método de Pago, en primer lugar la tabla pago esta encargada de registrar el monto y el horario donde se ralizó.

 Para la otra tabla para registrar la forma en la que pago en servicio el cliente hice la tabla Método de Pago que registra el nombre del método que fue utilizando para abonar, ya sea forma de efectivo o con tarjeta.

 Cree una tabla Horarios para todo lo que necesite tener uno, donde esta la hora y el minuto, esto sirve para saber tanto como el horario de un turno como para saber el horario de apertura o clausura de una sucursal.
 Debido a que tenemos varias sucursales me pareció necesario crear esta tabla, que presenta información sobre cada uno de los edificios donde se emplea.
